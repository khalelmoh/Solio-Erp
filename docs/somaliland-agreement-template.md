# Somaliland employment/payroll agreement worksheet

Status: **provisional organization template; unsigned and not legally validated**. USD only. Use monthly salary, an approved open amount or project compensation; no hourly base pay. The operator must replace placeholders and retain genuine employer/employee authorization before validating the ERP policy.

| Item | Required agreement |
| --- | --- |
| Parties and role | Employer, employee identity, position, supervisor, location and duties |
| Employment episode | New start, fixed-term end if any, previous departure/rehire reference |
| Compensation | Monthly USD basic salary or project/open pay; authorized monthly equivalent for statutory calculations |
| Work calendar | Agreed working days, hours, rest days and public holidays |
| Leave | Reviewed statutory entitlement, eligibility, carryover, actual balance and any agreed cash-out |
| Final salary | Earned days and approved supplements, reimbursements and deductions |
| Service gratuity | Reviewed Article 25 application; partial years explicitly resolved, otherwise manual review |
| Leave valuation | Agreed salary basis and divisor; 26 is an example requiring authorization |
| Notice and other entitlements | Contract/law basis, amount/calculation, evidence and approval |
| Tax | Current authorized tax treatment and separately approved payroll rule; no invented statutory rate |
| Advances | Separate receivable; no automatic final-pay recovery without lawful authority and explicit approval |
| Project allocations | New independently approved funding/project allocations; never duplicate salary across projects |
| Access and equipment | Issued property, account owners, return/revocation and rehire access review |
| Privacy | Record classes, lawful retention, legal holds, restricted financial evidence and backup disposal |
| Signatures | Employer, employee, date and independent HR/payroll/legal validation reference |

Sources for reviewer: [Law 31/2020 in ILO NATLEX](https://natlex.ilo.org/dyn/natlex2/r/natlex/fe/details?p3_isn=112608) and [government English labour-law publication](https://govsomaliland.org/uploads/files/2026/01/2026-01-21-07-44-12-976-1768981452.pdf).
